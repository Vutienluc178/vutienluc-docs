About this tool

          

            
Privacy

            

              Your files never leave your device. Conversion
              runs entirely in your browser via WebAssembly — nothing is
              uploaded to a server, ever.
            


            
One model

            

              Every format parses into the same document model and renders
              through the same Markdown serializer, so headings, nested
              lists, merged table cells, and footnotes come out consistent
              no matter the source format.
            


            
Detection

            

              The format is read from the file's bytes, not its extension,
              so a mislabeled file still converts correctly.
            


            
Speed

            

              Pure Rust compiled to WebAssembly, no ML models, no network
              calls: conversion typically finishes in a few milliseconds.
            


            
PDF

            

              Text-based PDFs convert locally. Scanned, image-only pages
              need OCR, which this tool does not currently perform.
